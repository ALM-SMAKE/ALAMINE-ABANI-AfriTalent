#  AfriTalent

AfriTalent est une plateforme web permettant de mettre en relation des freelances africains et des entreprises à la recherche de talents qualifiés.


#  Présentation du projet

Ce projet a été réalisé dans le cadre d'un travail académique afin de mettre en pratique les compétences acquises en développement web front-end.

L'objectif est de proposer une interface moderne, responsive et intuitive permettant de :

- Découvrir des profils de freelances ;
- Consulter les offres tarifaires ;
- Lire des articles de blog liés à la tech ;
- Contacter l'équipe AfriTalent ;
- Découvrir la plateforme et ses services.


#  Objectifs

- Concevoir un site web multi-pages.
- Utiliser HTML, CSS et JavaScript.
- Exploiter Bootstrap pour accélérer le développement.
- Mettre en œuvre Git et GitHub pour le suivi du projet.
- Produire une interface responsive adaptée à tous les écrans.

# Difficultés rencontrées

# 1. Compatibilité responsive
Certaines sections ne s'affichaient pas correctement sur mobile.

Solution :
Utilisation des media queries et des grilles Bootstrap.

# 2. Gestion des animations JavaScript
Les éléments utilisant la classe `.hidden` restaient invisibles.

*Solution :*
Correction de l'Intersection Observer et vérification des sélecteurs.
